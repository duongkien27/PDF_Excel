Chuyển đơn hàng PDF → Excel (theo mẫu)

Tải PDF đơn đặt hàng lên, kiểm tra/sửa dữ liệu trích xuất, rồi xuất ra file Excel đúng định dạng mẫu.

1. Tải file PDF

📄 Kéo thả file PDF vào đây, hoặc bấm để chọn file

2. Thông tin tiêu đề (mẫu công ty phát hành)

3. Danh sách sản phẩm 0 dòng

物料代码 品名 规格 数量 单位 备注

Dữ liệu được trích tự động từ layout bảng trong PDF — vì mỗi PDF có thể trình bày khác nhau, hãy kiểm tra lại từng ô trước khi xuất file, đặc biệt là cột 品名/规格.

4. Xuất Excel
